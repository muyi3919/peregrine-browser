GETTING STARTED

准备好，开始你的航程。

三步建立一个有独立存储、地区设置与代理出口的浏览环境。

01

导入节点订阅

在「节点订阅」粘贴 Clash 订阅链接，或选择本地配置文件。没有节点时，也可以使用直连。

02

创建浏览环境

选择国家与城市预设，调整语言、时区、定位和窗口大小，再为这个环境选择一个节点。

03

启动并开始浏览

点击环境卡片上的「启动」。每个环境独立保存 Cookie、网站存储和浏览记录，可同时运行。

了解你的环境设置

地区设置与出口 IP

国家和城市预设会填写语言、时区和经纬度。网站看到的 IP 国家取决于代理节点；选择日本地区并不会自动获得日本 IP。直连时使用本机网络出口。

定位权限

「询问」会在网站请求定位时提示；「允许」让网页 GPS 返回该环境设置的伪造坐标；「禁止」拒绝网站的定位请求。网站也可能根据 IP 推测位置。

独立指纹与数据隔离

环境拥有独立的浏览数据目录，复制环境只复制设置。独立指纹模式以固定种子调整音频、字体与部分矩形测量特征。默认启用游隼稳定像素策略，覆盖常用 Canvas / OffscreenCanvas / WebGL 读回；内存、屏幕和 UA 可独立设置。复制环境生成新种子，普通模式只隔离存储并调整地区。网站仍可能关联账号、IP 与其他特征。

订阅与代理内核

订阅必须包含可解析的 Clash 节点配置。节点名称中的国家标记只是推测，导入成功也不代表连接可用。代理环境启动需要本地代理内核。
